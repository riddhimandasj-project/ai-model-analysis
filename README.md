# AI Model Analysis

## About This Project

This repository is a beginner-friendly exploration of artificial intelligence, model behavior, and the quality of AI-generated answers.

The goal is to learn how to evaluate AI responses systematically instead of assuming that a confident answer is always correct.

## Research Questions

- How does the wording of a prompt affect an AI response?
- How often do different responses contain factual errors?
- Which responses are clearer and more useful?
- How can people check AI-generated information critically?

## First Experiment: Comparing AI Responses

### Objective

Compare two AI responses to the same question and evaluate their accuracy, clarity, relevance, and usefulness.

### Method

1. Choose a question with an answer that can be checked against reliable sources.
2. Ask two AI systems the same question, keeping the prompts as similar as possible.
3. Record both responses.
4. Verify important factual claims using reliable references.
5. Compare the responses using the criteria below.

### Evaluation Criteria

- **Accuracy:** Are the factual claims correct?
- **Clarity:** Is the explanation easy to understand?
- **Relevance:** Does the answer address the question?
- **Evidence:** Can important claims be verified?
- **Limitations:** What is missing, uncertain, or potentially misleading?
